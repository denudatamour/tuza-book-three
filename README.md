# A uniform gap below two for triangle packings and edge transversals in K₄-free graphs of book size at most three

Haimin Zhou · Independent Researcher · [haiminzhou.1@gmail.com](mailto:haiminzhou.1@gmail.com)

Let $\nu_\triangle(G)$ be the maximum number of edge-disjoint triangles in a finite simple graph $G$, and let $\tau_\triangle(G)$ be the minimum number of edges meeting every triangle. If $G$ is $K_4$-free and every edge belongs to at most three triangles, then

$$177\,\tau_\triangle(G)\le353\,\nu_\triangle(G).$$

The same inequality holds for packing and covering any specified family of triangles of $G$. No density or connectivity assumption is needed.

The proof assigns weights to ten local triangle profiles and compares the resulting packing bound with a random edge cover. Matching exchanges and a local packing argument supply the strict gap below two.
